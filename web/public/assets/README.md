# Recursos de Nexo

- `nexo-logo.png` y `nexo-chat-logo.png`: recortes a 4× de los logotipos de los PDF
  de bienvenida y chat aportados por el usuario. Se conservan sus trazos originales.
- `fonts/InterVariable.woff2`: Inter variable, fuente oficial de
  [rsms/inter](https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2).
  Licencia SIL OFL incluida en `fonts/Inter.LICENSE.txt`.
- `icons/*.svg`: iconos originales de
  [Feather 4.29.2](https://github.com/feathericons/feather/tree/v4.29.2/icons).
  Licencia MIT incluida en `icons/Feather.LICENSE.txt`.

Todos los recursos se sirven localmente; el navegador no consulta CDN ni fuentes
externas. `SHA256SUMS` registra las copias incorporadas.
